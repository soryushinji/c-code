## 编译方法

```bash
gcc -Wall -Wextra -o 程序名 源文件.c
```

例如：

```bash
cd 综合练习
gcc -std=c11 -finput-charset=UTF-8 -fexec-charset=GBK -o q1 第01题_数位分析器.c
q1
```

> **`-fexec-charset=GBK` 不能省** —— 否则中文在 Windows 控制台会乱码。

`-Wall -Wextra` 会打开编译器的全部检查，能帮你提前发现很多问题。

## 编码约定

**所有源文件一律使用 UTF-8 编码（无 BOM）**，VS Code 的设置里
`"files.encoding": "utf8"`。

> 之前 VS Code 设成 `gbk`，导致 UTF-8 文件全部显示成乱码
> （`上半部分` → `婂崐閮ㄥ垎`）。已经改掉。

如果编译出来的程序运行时中文乱码，说明控制台编码不是 UTF-8：

```bash
chcp 65001                      # 把控制台切到 UTF-8
gcc -fexec-charset=GBK -o q1 第01题_数位分析器.c   # 或者让输出用 GBK
```

## 自动同步
