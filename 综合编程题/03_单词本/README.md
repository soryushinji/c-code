# 03　单词本 + 小测验

## 题目要求

维护一个英中对照词库，7 个功能：

| # | 功能 | 要点 |
|---|---|---|
| 1 | 添加单词 | 重名拒绝、超长拒绝 |
| 2 | 列表显示 | 序号 + 英文 + 中文，对齐 |
| 3 | 查找 | 找到显示序号和中文 |
| 4 | 按字母排序 | 冒泡 + 手写字符串比较 |
| 5 | 删除 | 后面元素前移，数量 −1 |
| 6 | 小测验 | 随机抽 5 题、不重复、判对错 |
| 7 | 统计 | 总数 / 对错 / 正确率 / 平均长度 |
| 0 | 退出 | 真的结束程序 |

**禁用 `strcmp` / `strcpy`**（第 11 章才学），必须手写。

## 数据结构

```c
int  wordnum = 10;
char wordbook[1024][100];      /* 英文 */
char Chinesebook[1024][100];   /* 中文 —— 必须同步操作！ */
```

## 核心一：判等的唯一写法

```c
int j = 0;
while (a[j] == b[j] && a[j] != '\0') j++;
int equal = (a[j] == '\0' && b[j] == '\0');
```

**为什么不能用"数相同字符数"** ✗：
`banana` 和 `bananaXXX` 前 6 个字符都相同 → 数出来是 6 = 长度 → **误判为相等**。

## 核心二：交换整行

```c
for (k = 0; k < 100; k++)          /* 整行 100 字节，不要 [k+n] */
{
    temp[k]        = wordbook[a][k];
    wordbook[a][k] = wordbook[b][k];
    wordbook[b][k] = temp[k];
}
for (k = 0; k < 100; k++)          /* 中文必须同步换 */
{
    temp[k]           = Chinesebook[a][k];
    Chinesebook[a][k] = Chinesebook[b][k];
    Chinesebook[b][k] = temp[k];
}
```

## 踩过的坑

| 坑 | 后果 | 修法 |
|---|---|---|
| **`'\0'` 补在 `[strlen-1]`** | **最后一个字母被吃掉** | **`[strlen(s)]` 才是 `'\0'` 的位置** |
| **`wordbook[wordnum]` 而非 `wordnum-1`** | **写到下一行** | **下标对齐** |
| **判重 `pin == max`** | **前缀相同就判重** | **逐字符比到 `'\0'`** |
| **`if(eng[i] == wb[i]);` 多分号** | **无条件 `pin++`，永远判对** ✗✗ | **去掉分号** |
| **`replace_word[k + n]`** | **越界 1 格 = 写下一行** ✗✗ | **`[k]`** |
| **`temp=a; b=a; a=temp;`** | **两行都变成 a** | **`temp=a; a=b; b=temp;`** |
| **`n` 既当比较位置又当交换起点** | **比较错位 + 越界** | **一个变量一件事** |
| **`while` 比字符串没有 `'\0'` 保护** | **两词相同 → 无限比下去** | **`&& a[n] != '\0'`** |
| **`strlen` 在循环条件里** | **O(n²)，跑 100 次 vs 1 次** | **先存 `int n = strlen(s);`** |
| **`aveword` 用全局累加** | **每次调用都翻倍** | **用局部变量，每次从 0 算** |

## 一句话

> **`strlen(s)` 返回的值，正好就是 `'\0'` 的位置 —— 不是 `strlen(s)-1`。**
> **判等看"停下来的位置两边是不是都到头"，不是"数相同字符数"。**
