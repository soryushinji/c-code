# 02　五子棋

## 题目要求

15×15 棋盘，黑白轮流落子，任一方向连成 5 个即胜；支持悔棋。

| 功能 | 要求 |
|---|---|
| 开始新局 | 清空棋盘 |
| 落子 | `行 列`，越界/重复要提示 |
| 胜负判定 | 落子后从该点往 4 个方向数 |
| 悔棋 | 撤销上一步（进阶 +3） |
| 记录步数 | 显示当前第几手（进阶 +1） |

## 数据结构

```c
#define N 15
char chess[N][N];       /* '.' 空  '*' 黑  'O' 白 */
int  g_row, g_col;      /* 上一步落在哪 */
int  g_count = 0;       /* 第几手 */
```

## 核心：四方向连子

```c
int dr[4] = {0, 1, 1, 1};     /* 横 / 竖 / 两条斜 */
int dc[4] = {1, 0, 1, -1};

for (d = 0; d < 4; d++)
{
    int cnt = 1;
    for (k = 1; k < 5; k++)          /* 正方向 */
    {
        nr = r + dr[d] * k;  nc = c + dc[d] * k;
        if (nr < 0 || nr >= N || nc < 0 || nc >= N) break;
        if (chess[nr][nc] != who) break;
        cnt++;
    }
    for (k = 1; k < 5; k++)          /* 反方向 */
    {
        nr = r - dr[d] * k;  nc = c - dc[d] * k;
        if (nr < 0 || nr >= N || nc < 0 || nc >= N) break;
        if (chess[nr][nc] != who) break;
        cnt++;
    }
    if (cnt >= 5) return 1;
}
```

## 踩过的坑

| 坑 | 后果 | 修法 |
|---|---|---|
| **`read_move(int move, int row, int col)` 用普通参数** | **悔棋拿不到坐标** ✗✗ | **写成全局 `g_row` / `g_col`，函数里直接写** |
| **`scanf("%s", &s)` 多加 `&`** | **类型是 `char(*)[100]`** | **数组名本身就是地址** |
| **`read_move` 返回 `void`，EOF 后不知道** | **空转死循环** | **改成 `int`，返回 -1 表示 EOF** |
| **`read_move` 调了两次** | **白棋连下两子** | **一次读一行** |
| **只改黑棋分支，忘了白棋** | **一边能悔一边不能** | **改对称代码时搜一遍另一半** |
| **`is_win` 用 `num == 5`** | **六连反而判输** | **`num >= 5`** |
| **`move % 2` 判断黑白** | **先后手反了** | **显式维护 `who` 变量** |
| **斜线只查了一个边界** | **越界读，结果不可预测** | **`nr`、`nc` 两个都查** |

## 一句话

> **落子后从这个点往 4 个方向数，正反各数一半，任一方向 ≥5 就赢。**
> **悔棋要拿到坐标 —— 而普通参数改不了外面，必须用全局变量。**
