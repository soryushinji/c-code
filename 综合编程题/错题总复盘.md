## ① 指针与值传递

| # | 错误 | 后果 | 正确 |
|---|---|---|---|
| 1 | `read_move(int move, int row, int col)` | 函数改副本，外面拿不到坐标 | 用全局变量 `g_row` / `g_col` |
| 2 | `scanf("%s %s", &eng, &che)` | 类型是 `char(*)[100]` | 数组名不加 `&` |
| 3 | 悔棋读 `g_row`，但函数改的是形参 | 外面永远是 0 | 全局变量，函数直接写 |

**小提示**：问自己"这个参数，函数需要**改**它吗？" —— 要改就不能用普通参数。

## ② 字符串与 `'\0'`

| # | 错误 | 后果 | 正确 |
|---|---|---|---|
| 1 | `s[strlen(s) - 1] = '\0'` | 最后一个字母被吃掉 | `s[strlen(s)]` |
| 2 | `wordbook[wordnum][strlen(eng)]` | 写到下一行 | `wordbook[wordnum - 1]` |
| 3 | 判重 `pin == max` | 前缀相同就判重 | 逐字符比到 `'\0'` |
| 4 | `if (a[i] == b[i]);` | 分号 → 无条件 `pin++` | 去掉分号 |
| 5 | `wb[..][n - 1] == '\0'` | 永远为假 | `[n]` |
| 6 | `wb[..][n] == '\0'` | 恒真，条件无效 | 用"停下来的下标"判断 |
| 7 | `eng[random[k]]` | 下标用错数组 | `eng[num]` |
| 8 | `scanf("%s", eng)` | 溢出 | `%99s` |

**小提示**：`strlen(s)` 返回的值，正好就是 `'\0'` 的位置。

**判等的唯一写法**：

```c
int j = 0;
while (a[j] == b[j] && a[j] != '\0') j++;
int equal = (a[j] == '\0' && b[j] == '\0');
```

## ③ 二维数组

| # | 错误 | 后果 | 正确 |
|---|---|---|---|
| 1 | `wordbook[i][k + n]` | 越界 1 格 = 写下一行 | `[k]` |
| 2 | `wordbook[i] = "apple"` | 数组不能整体赋值 | `strcpy` 或逐字符 |
| 3 | `read_outer` 填 `[0..row-1]`，打印 `[1..row]` | 最后一行/列空白 | 两边范围对齐 |
| 4 | `char a[1][1024] = "apple"` | 初始化要花括号 | `= {"apple"}` |

**小提示**：`a[i][cols]` 就是 `a[i+1][0]` —— 行与行之间没有缝。

## ④ 循环与退出

| # | 错误 | 后果 |
|---|---|---|
| 1 | `while (k < mine)` 里漏 `k++` | 死循环 |
| 2 | 抽光后 `continue` 没出口 | 点名器卡死 |
| 3 | EOF 后 `void` 函数传不出信号 | 五子棋空转 |
| 4 | `if (note = -1)` 一个等号 | 第一轮就 break |
| 5 | `else if` 链 | 只打印第一个 |
| 6 | `recurse++` 传副本 | `while (recurse < 8)` 永不结束 |
| 7 | 答错 `continue` 不推进 `k` | 永远卡同一题 |

**小提示**：`while (i < n)` 的循环体里，必须能找到 `i` 的递增。`for` 比 `while` 安全。

## ⑤ 递归

| # | 错误 | 后果 | 正确 |
|---|---|---|---|
| 1 | `reveal` 没有边界检查 | 越界写 `outer[-1][-1]`，实测 128 次 | 先判 `1..row` |
| 2 | 没有"已开过"检查 | 两个 `'0'` 互相递归 → 栈溢出 | `if (outer[r][c] != '#') return;` |
| 3 | 忽略递归返回值 | 8 个邻居 8 次"被炸死" | `if (r == -2) return -2;` |
| 4 | `recurse` 参数控制方向 | 传副本，永不递增 | 每层用自己的 `dr`/`dc` 循环 |

**小提示**：递归三要素 —— 边界 / 已访问标记 / 每分支 `return`。
**递归口诀**：只传"我在哪"，不传"我数到几"。

## ⑥ 函数设计

| # | 错误 | 后果 |
|---|---|---|
| 1 | 一个 `n` 既当比较位置又当交换起点 | `[k+n]` 越界 |
| 2 | 一个 `picked_ID` 既存学号又存状态 | 重置后统计错 |
| 3 | 一个 `total` 同时表示"抽几次"和"人数" | `total - sum` 无意义 |
| 4 | `choice_print()` 名字说打印，实际在读 | 名不副实 |
| 5 | `void` 函数 `return 0` | 编译警告 |

**小提示**：一个变量只表达一件事。能写局部变量就别写全局。

## ⑦ 输入处理

| # | 错误 | 后果 |
|---|---|---|
| 1 | `scanf` 后不检查返回值 | EOF 被当成正常输入 |
| 2 | EOF 与"踩雷"都用 `-1` | 调用方分不清 |
| 3 | `%c` 前不加空格 | 吃掉上一轮的换行 |
| 4 | 清缓冲只清不判 EOF | EOF 后死循环 |
| 5 | `scanf("%s", &s)` | 多余 `&` |

**小提示**：`ret == 0` 和 `ret == EOF` 是两件事 —— 0 要清缓冲重试，EOF 要退出。

## ⑧ 边界与越界

| # | 错误 | 后果 | 正确 |
|---|---|---|---|
| 1 | `rand() % ((sum-1) - 0 + 1)` 当 `sum=0` | 除零，崩溃 `0xC0000094` | 先判 `sum == 0` |
| 2 | `rand() % (row + 1)` | 雷放到边框上 | `rand() % row + 1` |
| 3 | 斜线只查一个坐标 | 越界读 | 两个坐标都查 |

**小提示**：除以任何东西之前，先问"它会是 0 吗"。

## 三个习惯性根源

### ① 一个变量干两件事（4 次）

`n`（比较+交换）、`picked_ID`（学号+状态）、`total`（次数+人数）、`n`（长度+下标）

> 写代码前先问：这个变量能用一句话解释吗？**解释不了就拆。**

### ② 只改一半（3 次）

黑白棋只改一边、`flag` 有 `mark++` 没 `mark--`、交换只改一处

> 改对称的东西时，**改完立刻搜一遍另一半。**

### ③ 不看编译输出（2 次，但最耽误时间）

缺 `#include`、裸中文、`round` typo —— 都是编译错误，但代码被当成"运行了"

> **先看终端，再看代码。**

## 写代码前的 20 条自查

1. 每个变量只表达一件事
2. `while` 里能找到递增
3. `if (...)` 后面没有多余分号
4. `if (x = ...)` 不是 `==`
5. 递归有边界检查
6. 递归有"已访问"标记
7. 递归每个分支都有 `return`
8. `scanf` 返回值检查了
9. EOF 单独处理
10. `%99s` 限宽
11. `%c` 前有空格
12. `char` 数组不加 `&`
13. `'\0'` 补在 `strlen` 处
14. 判等用 `while` 走到不同/到头
15. 二维数组没有复合下标
16. 交换三步写对了
17. 除法/取模前判 0
18. 计时变量在循环外且初始化
19. 计数器清零在"每局"不是"每轮"
20. 编译 0 错误 0 警告，且跑的是新 exe
