## 数据结构

```c
#define RMAXN 27
#define CMAXN 40
char outer[RMAXN][CMAXN];   /* 表棋盘：玩家看到的 */
char inner[RMAXN][CMAXN];   /* 里棋盘：真值 */
int  rmine[500], cmine[500];/* 雷的坐标（沿用上局要用） */
```

**数组按最大尺寸声明，循环用实际尺寸** ✓ —— 这就是"难度分级"的实现方式。

## 核心一：边界检查 + 已访问标记

```c
int reveal(int rows, int cols, int row, int col)
{
    if (rows < 1 || rows > row || cols < 1 || cols > col) return 1;  /* ① 边界 */
    if (outer[rows][cols] != '#') return 1;                          /* ② 已访问 */

    outer[rows][cols] = inner[rows][cols];
    if (outer[rows][cols] == '*') return -2;                         /* 踩雷 */
    if (inner[rows][cols] != '0') return 1;                          /* 非零就停 */

    for (dr = -1; dr <= 1; dr++)
        for (dc = -1; dc <= 1; dc++)
        {
            if (dr == 0 && dc == 0) continue;
            r = reveal(rows + dr, cols + dc, row, col);
            if (r == -2) return -2;                                   /* ③ 立刻往上抛 */
        }
    return 1;                                                         /* ④ 每分支都有 return */
}
```

**递归三要素缺一不可** ✓：**边界 / 已访问标记 / 每分支 return**

## 核心二：8 邻居计数要用"影武者"

```c
char copy[27][40];
for (...) copy[i][j] = inner[i][j];       /* 先复制 */

for (i = 1; i <= row; i++)
    for (j = 1; j <= col; j++)
    {
        if (inner[i][j] == '1') { inner[i][j] = '*'; continue; }
        n = copy[i-1][j-1] + copy[i-1][j] + ... ;   /* 用 copy，不是 inner */
        inner[i][j] = n + '0';
    }
```

**为什么必须复制** ✗：`inner` 在循环里被改（`'1'` → `'*'`），**后面算邻居时会读到已改的值**。

## 踩过的坑

| 坑 | 后果 | 修法 |
|---|---|---|
| **`round` 撞 `<math.h>`** | **编译报错或警告** | **`g_round` 或改 `rounds`** |
| **裸中文 `里棋盘布置完成` 没加 `//`** | **`error: stray '\351' in program`** | **加 `//`** |
| **缺 `#include` 就编译，失败后直接跑** | **跑的是旧 exe，改的代码没生效** ✗✗ | **先看终端红字** |
| **查重循环漏 `k++`** | **死循环，选完难度就卡住** ✗✗ | **用 `for` 循环** |
| **`rand() % (row + 1)`** | **雷放到边框上** | **`rand() % row + 1`** |
| **`read_outer` 填 `[0..row-1]`，打印 `[1..row]`** | **最后一行/列空白** | **两边范围对齐** |
| **`reveal` 缺边界检查** | **越界写 `outer[-1][-1]`，实测 128 次** ✗✗ | **先判 `1..row`** |
| **`reveal` 缺"已开过"检查** | **两个 `'0'` 互相递归 → 栈溢出 → 窗口直接关掉** ✗✗ | **`if (outer[r][c] != '#') return;`** |
| **忽略递归返回值** | **8 个邻居 8 次"被炸死"** ✗✗ | **`if (r == -2) return -2;`** |
| **`if(note = -1)` 一个等号** | **第一轮就 break，程序"没反应"** ✗✗ | **`==`** |
| **`t_start` 未初始化且在循环内** | **计时永远 00:00** | **循环外 + 初始化** |
| **`mark = 0` 在循环内** | **标记数永远是 0** | **循环外** |
| **`if(mintime > total)`** | **数组名和整数比较，永远为真** | **`mintime[i]`** |
| **`else if` 链** | **只打印第一个难度** | **独立的 `if`** |
| **`flag` 覆盖已翻开的格子** | **数字丢失，永远赢不了** | **判 `== '#'` 才标记** |
| **`%c` 前不加空格** | **吃掉上一轮的换行** | **`scanf(" %c %d %d", ...)`** |
| **`recurse++` 控制方向** | **传副本，永不递增，死循环** | **每层用自己的 `dr`/`dc` 循环** |
| **调试 `printf` 没删** | **玩家直接看到所有雷** | **发布前搜一遍 `printf`** |

## 一句话

> **递归三要素：边界 / 已访问 / 每分支 return。**
> **栈溢出在 Windows 上是静默崩溃 —— 窗口直接关掉，没有任何提示。**
> **先看编译输出，再看代码。**
