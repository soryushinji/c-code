## 编译方式

统一命令（Windows + MinGW）：

```bash
gcc -Wall -Wextra -std=c11 -fexec-charset=UTF-8 -o app.exe xxx.c
```

**`-Wall -Wextra` 必加** —— 这个项目里至少 5 个 bug 是靠它发现的。

## 一句话经验

> **一个变量只表达一件事；一个状态只用一种表示。**
> **`while` 里必须能找到递增；递归必须有"已访问"标记。**
> **先看编译输出，再看代码。**
