# 01　随机点名器

## 题目要求

从一份学号名单里随机抽取 N 个人，**同一轮内不重复**；可以重置。

| 功能 | 要求 |
|---|---|
| 录入名单 | 学号 1~50，可重复录入直到输入 0 |
| 抽 1 人 | 抽一个没抽过的 |
| 抽 N 人 | 循环调用"抽 1 人" |
| 重置 | 所有人恢复"没抽过" |
| 查统计 | 已抽 / 未抽人数 |
| 退出 | 结束程序 |

## 数据结构

```c
#define MAXN 50
int g_id[MAXN];       /* 学号 */
int g_picked[MAXN];   /* 0 = 没抽过，1 = 抽过 */
int g_n = 0;          /* 实际人数 */
```

## 核心：怎么做到"不重复"

```c
int pick_one(void)
{
    int k, left = 0, i;

    /* ① 先数还有几个没抽 */
    for (i = 0; i < g_n; i++)
        if (!g_picked[i]) left++;

    /* ② 边界检查 —— 这一步最容易忘 */
    if (g_n == 0)  { printf("[提示] 名单是空的\n");      return -1; }
    if (left == 0) { printf("[提示] 所有人都抽过了\n"); return -1; }

    /* ③ 一直抽，抽到没抽过的为止 */
    do { k = rand() % g_n; } while (g_picked[k]);

    /* ④ 标记 */
    g_picked[k] = 1;
    return k;
}
```

## 踩过的坑

| 坑 | 后果 | 修法 |
|---|---|---|
| **没做第 ② 步** | **所有人抽过后 `do-while` 死循环** ✗ | **先数 `left`，为 0 返回 -1** |
| **`rand() % ((sum-1) - 0 + 1)` 当 `sum=0`** | **除零，崩溃 `0xC0000094`** | **先判 `sum == 0`** |
| **`picked_ID = -1` 既存学号又存状态** | **重置后统计错** | **拆成 `g_id[]` + `g_picked[]` 两个数组** |
| **`total` 同时表示"抽几次"和"人数"** | **`total - sum` 无意义** | **一个变量一件事** |
| **`void` 函数里 `return 0;`** | **编译警告** | **改成 `int` 返回或 `return;`** |

## 一句话

> **"不重复随机" = 已抽标记数组 + 重抽循环 + 先数剩余。** 三步缺一不可。
