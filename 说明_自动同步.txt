========================================================================
  GitHub 自动同步 —— 使用说明
========================================================================

仓库地址：https://github.com/soryushinji/c-code
本地目录：D:\code


------------------------------------------------------------------------
  它是怎么工作的
------------------------------------------------------------------------

  ┌─────────────────┐
  │ 你在 VS Code 里  │
  │ 编辑 new day.c   │
  └────────┬────────┘
           │ 保存（Ctrl+S）
           ▼
  ┌─────────────────────────────────────────┐
  │ 计划任务「代码自动同步到GitHub」          │
  │ 每 10 分钟自动运行 自动同步.ps1           │
  │   1. git add -A                          │
  │   2. 有改动才 git commit                 │
  │   3. git push 到 GitHub                  │
  └─────────────────────────────────────────┘

  也就是说：你只管写代码、按 Ctrl+S。
  最多 10 分钟后，GitHub 上就会多一条提交。


------------------------------------------------------------------------
  ⚠️ 重要：必须开着代理
------------------------------------------------------------------------

  你的电脑通过本地代理 127.0.0.1:7897（Clash / Mihomo）访问 GitHub。
  git 已经配置成走这个代理：

      git config --global http.proxy  http://127.0.0.1:7897
      git config --global https.proxy http://127.0.0.1:7897

  ★ 如果代理软件（Clash）没开，推送会失败。
    没关系 —— 改动会安全地保存在本地，等代理开了下次自动补推。

  查看/修改代理配置：

      git config --global --get http.proxy
      git config --global http.proxy http://127.0.0.1:7897


------------------------------------------------------------------------
  日常使用
------------------------------------------------------------------------

  【什么都不用做】
    正常写代码、Ctrl+S 保存。10 分钟内自动同步。

  【想立刻同步，不想等】
    在 VS Code 终端里运行：

        powershell -ExecutionPolicy Bypass -File "D:\code\自动同步.ps1"

    或者双击 D:\code\自动同步.ps1

  【看同步日志】

        Get-Content "D:\code\.sync.log" -Tail 20

  【看 GitHub 上的提交】
    浏览器打开 https://github.com/soryushinji/c-code/commits/main

------------------------------------------------------------------------
  常见问题
------------------------------------------------------------------------

Q: 推送失败怎么办？
A: 先看日志 Get-Content D:\code\.sync.log -Tail 20
   · 提示 "Connection was reset" → 代理没开，打开 Clash 即可
   · 提示要输入用户名密码 → 少了登录凭据，手动跑一次 git push，
     会弹浏览器让你授权

Q: 我想改同步频率（比如 5 分钟一次）？
A: 管理员 PowerShell 里：

       $t = Get-ScheduledTask -TaskName "代码自动同步到GitHub"
       $t.Triggers[0].Repetition.Interval = "PT5M"
       Set-ScheduledTask -TaskName "代码自动同步到GitHub" -Trigger $t.Triggers

Q: 想彻底关掉自动同步？

       Unregister-ScheduledTask -TaskName "代码自动同步到GitHub" -Confirm:$false

Q: 会不会把 .exe 传上去？
A: 不会。.gitignore 里排除了 *.exe、*.o、output/。

Q: 中文会不会变乱码？
A: 不会。所有 .c 文件都是 UTF-8，git 原样传输。
   VS Code 的 files.encoding 也已经是 utf8。

Q: 我不小心改坏了文件，想还原？
A: 在 D:\code 里运行：

       git checkout -- "路径\文件名.c"     还原单个文件
       git log --oneline                    看历史
       git reset --hard 某个提交号           整体回退
