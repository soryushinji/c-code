## 每题踩过的坑（一句话总结）

| 题 | 最大的坑 | 正确做法 |
|:--:|------|------|
| 1 | `0` 的位数 | 约定 0 是 1 位，并在注释里写明 |
| 2 | 高度边界 | `h=1` 时四种图案都要能打 |
| 3 | 整数除法 | `5/2` 要得 2.5，用 `double` |
| 4 | `ctype` 返回值是**位标志** | 只判**非零**，绝不能写 `== 1` |
| 5 | `while(n>0)` 一次都不执行 | `0` 要单独输出并算 1 位 |
| 6 | 数组开小了 | 质因数只存**质因数**，别存 1~n 的质数表 |
| 7 | 循环不变量 | 每轮必须**恰好消费 1 个字符**（0 个→死循环，2 个→跳字符） |
| 8 | 整数除法吃小数 | `(double)(a+b) / 2.0` —— **先转 double 再除** |
| 9 | `srand` 写在循环里 | `srand` 只在 `main` 开头调**一次** |
| 10 | 排序改掉了原数组 | 除「录入」外，**所有功能都在副本上操作** |

## 通用教训

1. **`getchar()` 返回 `int`，不是 `char`** —— 只有 `int` 能同时表示 0~255 和 `EOF`(-1)
2. **`!=` 配 `||` 恒为真** —— "全都不等于"要用 `&&`
3. **声明不是语句** —— `case 1:` 后不能直接跟 `int x;`，要用 `{}` 包起来
4. **跨迭代的状态要清零** —— 或者干脆把声明放进循环体
5. **先校验再写入** —— 用临时变量算完，通过了才赋给数组
6. **数组下标越界不会报错** —— 它会安安静静地踩坏旁边的变量

## 已知的题册错误（不要照抄）

题册示例里有几处算错，代码按**正确结果**写：

- **第 5 题**：示例的各进制加和是 3 次，但文字写「4 次」
- **第 7 题**：`xyzXYZ9` 是 **7 位**，题册写「满足 4/5 项」，正确是 **3/5 项**（且要报「长度不足 8 位」）
- **第 8 题**：示例的 90–100 段写 3 人，实际是 **2 人**；方差写 253.75，正确是 **277.75**
